# Third Party Rising — data sources

Everything under `data/packs/` and `data/us.json` is generated by `tools/data/build.mjs`
from the public sources below. Nothing is typed in by hand and nothing is invented: a field
that could not be sourced is `null`, and every approximation or derivation is described in
the affected pack's `estimates` array.

Rebuild: `cd tools/data && npm install && node build.mjs` (all states) or
`node build.mjs OH TX` (some states; `data/us.json` is always rewritten). Downloads are cached
in `tools/data/cache/` (gitignored, about 0.5 GB). Validate with `node tools/data/check.mjs`.
Last full build: 2026-11-09.

## Caveats that apply to every pack

- **Presidential returns are not certified results.** The compilation used is media-scraped. 2020 and
  2024 sum to within about 0.5% of the certified national totals; the 2016 file is an
  election-week count and is about 5% short nationally (roughly 3.3 M Democratic and 1.8 M Republican
  votes fewer than certified), most visibly in late-counting states. Swap in the MEDSL file below when it can be obtained.
- Alaska `pres` is the statewide result apportioned to boroughs by population (not observed by borough).
- Connecticut uses the 8 historical counties throughout; `pres["2024"]` is omitted there because the
  source reports 2024 by planning region. Kalawao County, Hawaii has no `pres` in any year (reported with Maui County).
- ACS figures are survey estimates with margins of error; small places can have `null` income/age/bach
  (suppressed by Census).
- Hawaii has no incorporated places, so its `places` are census-designated places with `kind: "cdp"`.
- New Hampshire house: Census publishes shapes for the 164 base districts only. Members elected from
  floterial districts are seated on a base district of the same county (approximate placement).
- Maine's non-voting tribal representatives are not included (they hold no numbered seat).
- Nebraska's legislature is nonpartisan; Open States lists no party, so `inc.party` is `"I"`.
- Party mapping: Democratic (incl. DFL, D-NPL, fusion lines beginning "Democratic") → `D`; Republican
  (incl. fusion lines) → `R`; Libertarian → `L`; Green → `G`; Independent / Nonpartisan / unaffiliated → `I`; anything else → `O`.
- Geometry is simplified (mapshaper, per-layer topology preserved, tiny islands dropped) and rounded
  to 4 decimal places. Alaska's western Aleutians keep positive longitudes (antimeridian not unwrapped).

## Not fetched

- **MIT Election Data and Science Lab, County Presidential Election Returns 2000–2024**
  (doi:10.7910/DVN/VOQCHQ, CC0 1.0) — `https://dataverse.harvard.edu/api/access/datafile/13573089`
  (`countypres_2000-2024.tab`, dataset version 20.0). This was the preferred election source. The
  dataset metadata is readable, but the file download returns HTTP 400 "You may not download this
  file without the required Guestbook response", i.e. it needs a person to fill in Dataverse's
  guestbook form. `build.mjs` still attempts the download on every run and logs the outcome; it
  does not parse the file. If someone downloads it by hand into
  `tools/data/cache/medsl/countypres_2000-2024.tab`, `loadElections()` must be extended to read it.
- **Census Data API** (`https://api.census.gov/data/...`) — now requires an API key; not used. The
  same ACS tables are read from the summary-file downloads listed above.
